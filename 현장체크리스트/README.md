## 지금 되는 것
- 설정(⚙) → 점검 기준정보 엑셀 가져오기 → 검사 결과 미리보기 → 저장
  - 오류(시트·열 없음, 빈 값, 중복, 읽을 수 없는 점수척도)가 있으면 저장할 수 없음
  - "시험용 더미 기준정보 불러오기"로 바로 시험 가능
- 회차 만들기 (연도·분기). 만들 때 기준정보를 복사해 두어 나중에 기준정보가 바뀌어도 지난 회차는 그대로
- 회차 → 휴게소 → 매장 화면과 진행률
- **체크리스트 입력** (항목 1개씩): 적합/부적합, 점수, 부적합이면 지적내용 필수
  - 누를 때마다 자동 저장. 지적내용은 글자마다 임시 버퍼에도 적어 두어, 앱이 갑자기 꺼져도 다음 실행 때 복구
  - 필수값이 빠진 항목은 "작성중"으로 보관하고(새로고침해도 유지) 진행률에는 넣지 않음. 내보낼 때는 결과를 비워 보고서에 '판정누락'으로 표시
  - 작성중 항목에서는 이전/다음/번호 이동이 막힘 → 채우거나 "이 항목 입력 지우기"
  - 위쪽 번호 동그라미: 초록 적합, 빨강 부적합, 점선 노랑 작성중
- **사진** (부적합일 때 1장 이상 필수)
  - "📷 사진 촬영" → **웹앱 안 카메라**(휴대폰 기본 카메라 앱 아님)로 촬영. 긴 변 1600px JPEG로 줄여 웹앱 안에만 저장, 갤러리에는 남지 않음
  - 카메라를 못 열면(권한 거부·카메라 없음) 안내 문구 표시. "파일에서 가져오기"는 PC 시험용
  - 썸네일을 누르면 크게 보기·삭제. 적합으로 바꾸거나 항목을 지우면 확인 후 사진도 삭제
  - 파일명 미리보기: `휴게소_점검항목.jpg`, 같은 휴게소·항목이 두 매장 이상이면 `_입점매장`, 한 칸에 여러 장이면 `_2`
  - 규칙이 바뀌면(예: 사진 필수 추가) 예전에 저장된 항목도 다시 검사해 작성중으로 돌림
  - 실제 휴대폰에서 카메라가 열리는지는 배포 주소(https)가 정해진 뒤 확인
- **검토 · 집계** (회차 화면 아래 "검토 · 집계 보기")
  - 휴게소별: 점검·적합·부적합·작성중·미입력·부적합%·평균점수
  - 항목별 부적합 (점검항목 × 휴게소)
  - 확인 필요: 작성중 항목(빠진 값 표시), 매장별 미입력 항목 → 누르면 그 항목으로 바로 이동
  - 지적사항 목록 (점수·사진 수·지적내용)
  - 부적합%는 입력완료 항목만으로 계산
  - 평균점수는 보고서 도구와 같은 방식: 점수가 입력된 모든 항목(작성중 포함)의 평균
  - 숫자끼리 맞는지 자체 검산, 안 맞으면 빨간 경고
- **시정 대기** (회차 화면의 "시정 대기 n건" 버튼, 기한 초과가 있으면 빨간색)
  - 저장된 부적합 항목을 기한 초과 → 확인 필요 → 진행 중(기한 가까운 순) → 시정 완료(접힘) 순서로 표시
  - 시정 기한 = 지적일 + 14일. 기한 안에 재방문해 "시정 완료"로 기록해야 완료 (판정 규칙은 보고서 도구와 같음)
  - 항목을 누르면 지적내용·사진을 보고 재방문일(오늘로 입력 버튼)과 시정 결과(완료/미완료)를 저장
  - 재방문일이 지적일보다 빠르거나 오늘보다 늦으면, 또는 완료인데 날짜가 없으면 저장 안 됨
  - **조치 후 사진** (선택): 재방문 화면에서 "📷 조치 후 사진 촬영" → 찍으면 바로 저장. 파일명 `휴게소_점검항목[_매장]_조치후[_n].jpg`
    - 내보내기: `조치사진파일` 열, 사진은 `사진/{재방문일}/` 폴더 → 한글 보고서 사진란에 "(조치 후)"로 지적 사진 옆에 표시
    - 재방문 기록을 지우면 조치 후 사진도 지울지 묻고, 점검 화면에서 적합으로 바꾸거나 항목을 지우면 함께 삭제
  - 시험용: 주소 끝에 `?d=2026-11-25`처럼 붙이면 그 날짜를 기준일로 봄
- **업체 시정 요구 문구** (시정 대기 화면 → 휴게소 버튼) — 문구만 만들고 **보내지 않음**
  - A 메일 / B 공문 본문 / C 문자 세 가지. 형식·규칙은 기존 `hygiene-correction-request` skill과 같음
  - 미완료 부적합만 포함. 완료(재방문 확인)는 제외, 완료 표시인데 재방문일 없으면 제외하고 "확인 부탁드릴 사항"에 표시
  - 기한이 지난 항목: "(기한 경과) → [확인 필요: 새 기한]" + 새 기한·문구 강도를 묻는 질문 (규칙 없이 담당자가 매번 결정)
  - 운영업체명은 입력칸에 적은 것만 사용 (비우면 [확인 필요: 운영업체명]). 휴게소별로 회차에 기억
  - 각 문구는 고칠 수 있는 칸 + 복사 버튼. 지적내용은 입력한 그대로 들어가므로 내부 메모는 지우고 보내기
  - "첨부할 사진 zip 받기": 문구에 넣은 지적사항의 사진만, 문구의 첨부 파일명과 같은 이름으로
- **엑셀 + 사진 내보내기** (회차 화면 아래 "엑셀 + 사진 내보내기")
  - `위생점검_{연도}_{n}Q.zip` = `위생점검결과_{연도}_{n}Q.xlsx`(휴게소별 시트) + `사진/{YYYYMMDD}/…jpg`
  - 압축을 `D:\영업파트\위생점검\{연도}\{n}분기\`에 풀면 기존 폴더 구조와 같음 → 보고서 도구(make_report.py)로 바로 보고서 생성
  - 보고서 도구는 `사진파일` 열로 사진을 연결 (두 매장·여러 장 사진도 정확히 연결)
  - 모든 칸을 한 행씩 내보냄: 작성중은 결과를 비우고 비고에 "작성중(입력값: …) — 빠진 값", 미입력은 비고 "미입력"
    → 보고서의 점검건수·판정누락·평균점수가 웹앱 검토 화면과 같아짐
  - 열: 점검일 · 입점매장 · 점검항목 · 결과 · 점수 · 지적내용 · 매장담당자 · 연락처 · 지적일 · 재방문일 · 완료여부 · 사진파일 · 비고
  - "담당자 이름·연락처를 가려서 내보내기" 선택 가능 (기본은 원본, 보고서 도구가 가림)
- **오프라인**: 한 번 열면 화면 파일이 기기에 저장되어(`sw.js`), 통신이 끊겨도 열리고 입력·저장됨. 통신이 끊기면 위쪽에 노란 안내 줄
  - 홈 화면에 추가(설치) 가능: `manifest.json`, `icons/`
  - 화면 파일을 고친 뒤에는 `sw.js`의 `CACHE` 이름(현재 v8)을 올려야 기기들이 새 파일을 확실히 받음
  - 통신이 될 때는 파일마다 서버에 바뀌었는지 확인(no-cache)하므로, 업데이트 후 새·옛 파일이 섞이지 않음
- **회차 관리** (회차 화면 맨 아래)
  - 백업 파일 내려받기: `위생점검백업_{연도}_{n}Q_{날짜-시각}.zip` (회차 전체 + 사진). 대체 담당자 인계·기기 교체용
  - 설정(⚙) → 백업 파일 가져오기: 내용 미리보기 → 같은 회차가 있으면 "백업 내용으로 바꾸기" 경고 후 덮어쓰기
  - 이 기기에서 회차 삭제: 입력·사진 모두 삭제. 마지막 변경 뒤로 백업·내보내기를 안 했으면 한 번 더 경고
  - 마지막 변경·백업·내보내기 시각 표시, 변경 뒤 미백업이면 빨간 안내
  - 백업 파일에는 담당자 연락처·사진이 들어 있으므로 사내 경로로만 전달
- 담당자 이름·연락처, 지적내용 속 전화번호는 화면에 가려서 표시

## 자동 테스트
- **웹앱 자가 점검**: 설정(⚙) → "자가 점검 실행" (또는 `/tests/`). 56개 항목, 열면 바로 실행되고 화면에 통과/실패 표시. 실제 데이터는 건드리지 않음
- **보고서 도구**: `python ..\점검보고서_자동화\test_make_report.py` (6개 항목, 한글 변환 없이 1~2초)
- 항목별 기준·입력 예시와 사람이 확인할 항목: [../검증기준.md](../검증기준.md)

## 구조
| 파일 | 역할 |
|---|---|
| `index.html`, `css/app.css` | 화면 틀 (휴대폰 세로 기준, 다크 모드 지원) |
| `js/app.js` | 화면과 이동 |
| `js/db.js` | 브라우저 저장소(IndexedDB). 데이터는 이 기기 안에만 저장 |
| `js/xlsx.js` | 엑셀 읽기 (외부 라이브러리 없이 브라우저 기본 기능만 사용) |
| `js/master.js` | 기준정보 검사, 마스킹 |
| `js/entry.js` | 점검 입력 규칙 (필수값 검사, 저장/작성중 구분, 규칙 변경 시 재검사) |
| `js/photo.js` | 사진 축소, 파일명 규칙 |
| `js/summary.js` | 회차 집계·자체 검산 |
| `js/export.js` | 내보낼 행·사진 폴더 구성 |
| `js/followup.js` | 시정 기한·상태 계산, 재방문일 검사 |
| `js/backup.js` | 회차 백업 파일 만들기·읽기·검사 |
| `js/notice.js` | 업체 시정 요구 문구 (메일·공문·문자) |
| `js/camera.js` | 웹앱 안 카메라 (지적 사진·조치 후 사진 공용, 갤러리에 남지 않음) |
| `tests/` | 자가 점검 화면 (자동 테스트 56개) |
| `sw.js`, `manifest.json`, `icons/` | 오프라인 동작, 홈 화면 설치 |
| `js/xlsx-write.js`, `js/zip.js` | 엑셀·zip 파일 쓰기 (외부 라이브러리 없음) |
| `sample/test_result_dummy_2026_4Q.xlsx` | 집계 대조 시험용 더미 결과 (보고서 도구 시험에 쓴 파일의 사본) |
| `sample/` | 더미 기준정보 (정상 / 오류 시험용). 생성기: `../더미데이터/make_master.py` |

외부 서버나 인터넷 라이브러리를 쓰지 않습니다. 네트워크 요청은 이 웹앱 자신의 파일뿐입니다.
