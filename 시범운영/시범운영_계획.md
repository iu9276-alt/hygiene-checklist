## B. 휴대폰 확인 (점검 1주 전, 사무실에서)

휴대폰마다 아래를 확인하고 기종·OS를 적어 둡니다.

| # | 확인 | 본인 휴대폰 | 대체 담당자 휴대폰 |
|---|---|---|---|
| B1 | 주소로 웹앱이 열림 | ☐ | ☐ |
| B2 | 홈 화면에 추가 → 아이콘으로 열림 | ☐ | ☐ |
| B3 | 📷 사진 촬영 → 카메라 권한 허용 → 후면 카메라로 찍힘 | ☐ | ☐ |
| B4 | 찍은 사진이 **휴대폰 갤러리(사진 앱)에 생기지 않음** | ☐ | ☐ |
| B5 | 비행기 모드 → 웹앱 다시 열기 → 입력·사진 저장됨 → 상단에 "통신 끊김" 표시 | ☐ | ☐ |
| B6 | 비행기 모드 해제 후에도 입력 그대로 | ☐ | ☐ |
| B7 | 백업 파일 내려받기 → 다른 휴대폰에서 가져오기 (인계 연습) | ☐ | ☐ |
| B8 | 시험 회차 삭제 → 회차 목록에서 사라짐 | ☐ | ☐ |
| | 기종 / OS / 브라우저 | | |

B3·B4가 안 되면 시범 운영 전에 고쳐야 합니다 (갤러리 보관 안 함은 결정 사항).

## C. 점검 당일

1. 휴게소마다 웹앱으로 입력하면서 **종이 체크리스트에도 같이 기록**
2. 부적합은 웹앱으로 사진 촬영 (평소 카메라 사진은 찍지 않음)
3. 매장마다 진행률 확인, 작성중(노란 점선) 항목이 남지 않게
4. 불편했던 점은 그때그때 메모 (아래 E)

## D. 사무실 (점검 직후)

1. 웹앱 검토 화면에서 작성중·미입력 0건 확인
2. 엑셀 + 사진 내보내기 → `D:\영업파트\위생점검\{연도}\{n}분기\`에 압축 풀기
3. 보고서 도구 실행 → 한글 보고서 초안
4. 회차 백업 파일도 받아 두기
5. 결재 상신 후, 휴대폰에서 회차 삭제 (사진·연락처 정리)

### 시간 기록

| 구간 | 걸린 시간 |
|---|---|
| 현장 입력 (휴게소별 합계) | 분 |
| 내보내기 + 압축 풀기 | 분 |
| 보고서 도구 실행 + 초안 검토·수정 | 분 |
| **사무실 작업 합계** (기준선: 재입력·사진 정리 회차당 2~4시간) | 분 |
