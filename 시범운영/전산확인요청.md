# 위생점검 현장 체크리스트 웹앱 — 배포 위치 확인 요청

> 요청: 영업파트 휴게시설 담당 → 전산 담당
> 관련 문서: [BRD.md](../BRD.md), [PRD.md](../PRD.md)

## 1. 무엇을 요청하나요

휴게소 위생점검(분기 1회)을 **개인 휴대폰**으로 현장에서 입력하는 웹앱을 만들었습니다.
개인 휴대폰에서 열 수 있는 **https 웹 주소 하나**가 필요합니다. 아래 둘 중 가능한 방법을 알려 주세요.

| 방법 | 내용 | 필요한 것 |
|---|---|---|
| ① 외부 정적 호스팅 | GitHub Pages 같은 외부 무료 호스팅에 **화면 파일만** 올림 | 외부 호스팅 사용 허용 여부 |
| ② 사내 서버 | 사내 웹서버에 정적 파일로 올리고, 개인 휴대폰(외부망)에서 접속 가능하게 함 | 외부 접속 가능한 https 주소 |

개인 휴대폰 업무 사용은 이미 허용받았습니다 (2026-11-18 확인).

**두 방법 모두 바로 올릴 수 있게 준비해 두었습니다.** 같은 배포 묶음(`배포\위생점검웹앱_배포_YYYYMMDD.zip`) 하나로 ①·② 어느 쪽에도 올릴 수 있고, ②용 IIS(`web.config`)·Apache(`.htaccess`)·nginx(예시) 설정도 들어 있습니다. 올리는 방법과 올린 뒤 확인 순서는 [배포안내.md](../배포/배포안내.md)에 있습니다.

## 2. 올리는 것 (화면 파일만, 약 160KB)

```
index.html  manifest.json  sw.js
css/app.css
js/*.js (13개)
icons/icon-192.png  icons/icon-512.png
sample/checklist_master_dummy.xlsx   (시험용 가짜 데이터, 빼도 됨)
```
- 서버 프로그램·데이터베이스가 **없습니다**. 파일을 그대로 두기만 하면 됩니다 (정적 호스팅).
- 외부 라이브러리·외부 사이트 호출이 **없습니다**. 웹앱은 자기 파일 외에는 어떤 주소로도 요청을 보내지 않습니다.
- 페이지 안에 보안 규칙(CSP)을 넣어, 자기 주소 외 접속을 브라우저가 막습니다 (외부 호스팅처럼 서버 헤더를 못 바꾸는 경우에도 적용).

## 3. 데이터는 어디에 저장되나요 (보안)

| 데이터 | 저장 위치 | 서버로 전송 |
|---|---|---|
| 점검 입력값 (적합/부적합, 점수, 지적내용) | 각 휴대폰 브라우저 저장소(IndexedDB) | **없음** |
| 업체 담당자 이름·연락처 | 각 휴대폰 브라우저 저장소 | **없음** (화면에는 가려서 표시) |
| 지적사항 사진 | 각 휴대폰 브라우저 저장소. 웹앱 안 카메라로 찍어 **휴대폰 갤러리에 남지 않음** | **없음** |
| 결과 엑셀·사진 | 담당자가 직접 내려받아 사무실 PC로 옮김 | **없음** |

- 호스팅 서버에는 화면 파일만 있고, **업무 데이터가 한 번도 올라가지 않습니다.**
- 내보내기를 마친 회차는 휴대폰에서 지울 수 있습니다 (삭제 기능 있음).
- 대체 담당자 인계는 백업 파일을 **사내 메일**로 전달하는 방식입니다.

## 4. 확인 부탁드리는 것

1. ①·② 중 가능한 방법과 주소
2. (①이면) 외부 정적 호스팅 사용에 별도 승인 절차가 있는지
3. (②이면) 개인 휴대폰에서 접속할 때 VPN 등 추가 절차가 있는지
4. 웹앱이 휴대폰 **카메라 권한**을 요청합니다 (지적사항 촬영용). 문제가 없는지

## 5. 확인 후 진행

주소가 정해지면 실제 휴대폰으로 카메라·오프라인 동작을 확인하고, 다음 분기 점검 1회를 종이와 병행해 시범 운영합니다 ([시범운영_계획.md](시범운영_계획.md)).
