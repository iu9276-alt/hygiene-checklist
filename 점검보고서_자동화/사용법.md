# 위생점검 결과 → 한글 보고서 초안 자동 생성

## 실행
```bash
python make_report.py --excel "<점검결과.xlsx>" --photos "<사진 폴더>" --manual "<수작업집계.xlsx(선택)>" --out "<출력 폴더>" --round "2026년 4분기"
```
- 결과: `<출력 폴더>\위생점검_결과보고_<회차>_초안.hwp` (+ 같은 내용의 .pdf, .html)
- 필요: Python + openpyxl, 한글 2020 (HWPFrame.HwpObject)
- 원본 엑셀·사진은 읽기만 함. 사진은 출력 폴더 `_img`에 사본을 두고 보고서 안에 넣음

## 입력 규칙 (현재 가정 — 실제 파일로 바꿀 때 확인)
| 항목 | 규칙 | 출처 |
|---|---|---|
| 시트 | 휴게소별 1시트, 시트 이름 = 휴게소명 | 업무_맥락.md |
| 필수 열 | 점검일, 입점매장, 점검항목, 결과(적합/부적합), 점수 | 더미 기준 (실제 열 이름 미확인) |
| 선택 열 | 지적내용, 매장담당자, 연락처, 지적일, 재방문일, 완료여부(Y/N) | 더미 기준 |
| 점수 | 1~5 | 더미 기준 (실제 척도 미확인) |
| 사진 | `사진\YYYYMMDD\휴게소_점검항목.jpg` (띄어쓰기·가운뎃점 무시) | 인터뷰 답변 |
| 시정 완료 | 지적일 +14일 안에 재방문, 완료여부 Y | 업무_맥락.md |

현장 체크리스트 웹앱이 내보내는 `사진파일`, `비고` 열도 알고 있는 열로 처리.
- `사진파일`에 파일명이 있으면 **그 파일을 그대로 연결** (쉼표로 여러 장). 같은 이름이 여러 폴더에 있으면 그 행 점검일 폴더(YYYYMMDD)를 우선
- 적힌 파일이 사진 폴더에 없으면 검산표 ①·⑤에 "사진파일 열에 적힌 파일이 없음"으로 표시
- `사진파일` 값이 없는 행(예전 엑셀)은 기존 파일명 규칙 `휴게소_점검항목.jpg`로 찾음
- `조치사진파일`: 재방문 때 찍은 조치 후 사진. 재방문일 폴더에서 찾아, 보고서 사진란에 지적 사진 옆 "(조치 후)"로 표시
- `비고`는 집계에 쓰지 않음
열 순서가 바뀌어도 열 이름으로 찾음. 모르는 열·없는 열·결과 빈칸은 고치지 않고 부록 ④에 보고.

## 검산 (보고서 부록)
① 자동 검산(행 수, 적합+부적합, 지적 건수, 사진 누락, 수작업 차이) ② 과거 수작업 대조
③ 무작위 표본 5건(원본 시트·행 표시) ④ 확인 필요 데이터 ⑤ 사진 연결 ⑥ 개인정보 마스킹

## 자동 테스트
```bash
python test_make_report.py
```
집계(R-1)·사진 누락(R-2)·사진파일 연결(R-3·R-4)·조치 후 사진(R-5)·시정 상태(R-6). 한글 변환 없이 실행, 임시 파일은 자동 삭제.

## 알려진 한계
- `사진파일` 열이 없는 예전 엑셀에서, 같은 휴게소·같은 항목이 두 매장 이상 부적합이면 파일명 규칙만으로 사진을 구분할 수 없음 → 부록 ④에 표시 (웹앱에서 내보낸 엑셀은 `사진파일` 열로 해결됨)
- 사진 속에 찍힌 글자(이름·번호)는 검사하지 않음
- 실제 사내 결재 양식이 정해지면 HTML 서식을 그 양식에 맞춰야 함
